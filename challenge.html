About the Challenge

The G2A Jenga Challenge evaluates whether robot policies can reason about fragile structure, predict action consequences, and complete long-horizon manipulation without destabilizing the tower.

The challenge is built on TOWER, a simulation benchmark for bimanual tower manipulation. Participants develop policies using released simulated demonstrations and simulation assets, and are evaluated on standardized manipulation tasks.

Core Question

Can a robot use visual and physical context to choose actions that make progress while preserving tower stability?

02

Benchmark Tasks

The public simulation release contains three task families, each with 2-layer and 3-layer variants.

Task 1

Tower Transfer

Transfer blocks between source and target tower configurations while maintaining stable structure.

2 layers · 3 layers
Task 2

Cross Tower Transfer

Perform sequential cross-tower transfers while preserving the target arrangement throughout execution.

2 layers · 3 layers
Task 3

Vertical Stacking

Build stable vertical block structures through precise sequential manipulation.

2 layers · 3 layers

Evaluation & Participation

Policies are evaluated on standardized simulation tasks, with task success as the primary measure of performance.

Metric What it measures Direction
Success Rate Complete-task success across evaluation episodes. ↑
Level Progress Rate Required task progress completed before termination. ↑
Collapse Rate Episodes in which the tower collapses during execution. ↓
Completion Time Time required to complete the task. ↓
