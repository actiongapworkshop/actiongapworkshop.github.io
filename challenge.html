01

Challenge Overview

The G2A Jenga Challenge is an interactive robot manipulation benchmark for evaluating Action-Conditioned World Models (ACWMs), World Action Models (WAMs), and related approaches in settings where understanding the consequences of an action is critical to success.

Jenga provides a compact but challenging testbed for spatial reasoning, physical forecasting, and closed-loop interaction. Before executing an action, a capable model should be able to reason about the current tower structure, predict the outcomes of alternative actions, and select actions that accomplish the task without destabilizing the scene.

The challenge evaluates this capability through manipulation tasks involving block transfer, extraction, replacement, and coordinated interaction. Rather than evaluating visual prediction alone, the benchmark asks whether predicted future outcomes can support executable and reliable robot behavior.

Central Question

Can a model forecast the physical consequences of different robot actions before execution, and use those forecasts to choose actions that successfully manipulate a structured and fragile environment?

Core Capability

Spatial Understanding → Action Rollout → Physical Forecasting → Action Selection → Execution

02

Benchmark Environment

The G2A Jenga benchmark provides interactive simulation environments reconstructed from corresponding real robot setups, enabling controlled and repeatable evaluation of spatial reasoning, physical forecasting, and action-conditioned manipulation.

The simulation environment is built in Isaac Sim and aligned with the corresponding real-world setup in scene geometry, robot configuration, camera observations, and interaction dynamics. Jenga blocks are modeled as interactive physical objects with contact and collision behavior, allowing models to reason about candidate actions and their physical consequences.

03

Challenge Phases

The challenge progresses from controlled single-arm simulation to coordinated bimanual manipulation evaluated in both simulation and the physical world.

Phase 1 · Sim Only

Single-Arm Jenga Manipulation

Participants develop and evaluate models in a single-arm interactive simulator corresponding to the real environment. The focus is on spatial reasoning, action forecasting, contact-aware planning, and manipulation under fragile physical constraints.

Single arm · Simulation · Multiple manipulation tasks
Phase 2 · Sim & Real

Bimanual Sim-to-Real Evaluation

Phase 2 extends the benchmark to coordinated dual-arm manipulation. Models are evaluated in simulation and the corresponding physical robot setup, enabling direct study of simulation performance, real-world performance, and their correlation.

Dual arm · Simulation + Real · Sim-to-real correlation
04

Phase 1 Tasks

Phase 1 contains Jenga manipulation tasks with increasing requirements for spatial reasoning, physical forecasting, contact-aware interaction, and long-horizon execution.

Easy

Tower Transfer

Transfer the center block from selected layers of a source tower to the corresponding positions of a target tower. Evaluation instances vary in the number and location of blocks that must be transferred.

Spatial correspondence · Pick-and-place · Long-horizon consistency
Medium

Cross-Tower Transfer

Manipulate a cross-oriented Jenga structure by sequentially transferring blocks between towers while preserving the intended structure and avoiding collapse.

Sequential manipulation · Structure preservation · Stability
Medium

Block Replacement

Insert a new block to push a designated target block out of the tower, while simultaneously occupying and preserving the target block's original position.

Contact reasoning · Action forecasting · Precise insertion

Tower Transfer Evaluation Set

The current Tower Transfer setup includes 1-, 2-, and 3-layer variants, with 50 evaluation instances per setting for a total of 150 instances. Additional task configurations may be added before the final benchmark release.

05

Evaluation

Models are evaluated on both task completion and the physical quality of their interaction with the Jenga structure.

Metric Description Direction
Success Rate Fraction of evaluation episodes in which the complete task is successfully finished. ↑
Level Progress Rate Fraction of required tower levels successfully completed before termination. ↑
Collapse Rate Fraction of episodes in which the Jenga structure collapses during execution. ↓
Completion Time Time required from task initialization until successful completion or termination. ↓
Leaderboard Ranking

Success Rate will be used as the primary benchmark metric in the initial release. Progress, collapse, and completion time will be reported as complementary metrics. The final ranking protocol will be announced with the evaluation release.

06

Data & Participation

We provide the simulation environment, task definitions, demonstration data, evaluation configuration, and standardized test protocol required to participate.

What We Provide

  • Simulation environment. The Jenga simulation environment and task configurations used for challenge evaluation.
  • Training and test splits. Standardized train/test settings for each released task.
  • Demonstrations. Demonstration trajectories for the released task configurations, together with representative real-robot trajectories where applicable.
  • Robot actions. Standardized joint-space representations and reference trajectories for interfacing participant models with the evaluation environment.
  • Evaluation code. Evaluation scripts, task configuration files, and submission-format validation tools.
  • Leaderboard. A public leaderboard for tracking benchmark performance across challenge submissions.

Submission Flow

Workflow

Train / Demo Data → Participant Model → Test Set → Model Output → Evaluation Server → Leaderboard

How to Participate

  • 1. Download. Download the simulator, task definitions, demonstrations, and starter code from the challenge repository.
  • 2. Develop. Train, adapt, or prompt your model using the permitted resources.
  • 3. Run. Produce outputs for the released challenge test inputs using the required submission format.
  • 4. Submit. Upload the model outputs to the evaluation system.
  • 5. Evaluate. Valid submissions are evaluated using the official benchmark metrics and displayed on the leaderboard.

07

Phase 2: Bimanual Sim-to-Real

Phase 2 extends the benchmark from single-arm simulation to coordinated bimanual manipulation evaluated in both simulation and the real world.

Participants will receive the corresponding simulation environment and task data for the bimanual setup. Evaluation will compare simulated performance with execution on the physical robot system, allowing the challenge to study not only task success but also how reliably simulation performance predicts real-world behavior.
